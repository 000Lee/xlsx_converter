# xlsx_converter

한글(.hwp) 시간표를 서식 그대로 엑셀(.xlsx)로 바꿔주는 프로그램입니다.

셀 병합 · 테두리 · 배경색 · 글꼴 · 글자색 · 취소선 · 열너비 · 행높이를
한글에서 보이던 모습 그대로 옮깁니다. 데이터만 옮기는 게 아닙니다.

**한/글이나 엑셀이 설치되어 있지 않아도 변환됩니다.**
.hwp 파일 내부를 직접 읽기 때문에 프로그램 설치가 필요 없습니다.

---

## 사용법 (프로그램만 받아서 쓰기)

### 1. 프로그램 받기

[**Releases 페이지**](../../releases/latest)에서 `hwp2xlsx.exe`를 내려받습니다.
파일 하나만 받으면 되고, 파이썬 같은 건 설치할 필요 없습니다.

### 2. 변환하기

둘 중 편한 방법을 쓰시면 됩니다.

**방법 A — 폴더에 넣고 더블클릭 (권장)**

1. 변환할 `.hwp` 파일들을 한 폴더에 모읍니다
2. 그 폴더 안에 `hwp2xlsx.exe`를 **복사해 넣습니다**
3. `hwp2xlsx.exe`를 **더블클릭**합니다
4. 같은 폴더에 생긴 **`xlsx` 폴더** 안에 결과물이 있습니다

**방법 B — 끌어다 놓기**

`.hwp` 파일(여러 개 선택 가능)이나 폴더를 `hwp2xlsx.exe` **아이콘 위로** 끌어다 놓습니다.
원본이 있던 자리에 `xlsx` 폴더가 생깁니다.

> 아이콘에 정확히 놓아야 합니다. 폴더 빈 공간에 놓으면 아무 일도 일어나지 않습니다.
> 잘 안 되면 방법 A를 쓰세요.

### 3. 처음 실행할 때 뜨는 경고

서명되지 않은 프로그램이라 윈도우가 한 번 막습니다.

> **Windows가 PC를 보호했습니다**

**`추가 정보`** → **`실행`** 을 누르면 됩니다. 다음부터는 안 뜹니다.

### 잘 안 될 때

실행하면 exe 옆에 **`변환로그.txt`** 가 생깁니다. 무엇을 찾았고 어디에 저장했는지,
실패했다면 그 이유가 적혀 있습니다.

| 상태 | 원인 |
| --- | --- |
| 로그 파일이 아예 안 생김 | 프로그램이 실행되지 않음 (백신 차단이거나 끌어다 놓기 실패) |
| `변환할 .hwp 파일이 없습니다` | 파일을 못 찾음 — 로그의 `찾아본 곳`을 확인 |
| `FAIL` | 변환 중 오류 — 사유가 함께 적힘 |

창이 순식간에 닫혀서 안 보이면 명령 프롬프트에서 실행하세요.

```
cd 프로그램이_있는_폴더
hwp2xlsx.exe
```

## 변환되는 항목

| 항목 | 지원 |
| --- | --- |
| 셀 병합 | O |
| 테두리 (종류 · 굵기 · 색) | O |
| 셀 배경색 | O |
| 글꼴 · 크기 · 굵게 · 기울임 | O |
| 글자색 (한 칸 안에서 색이 섞여도 유지) | O |
| 취소선 | O |
| 밑줄 | O |
| 셀 안 줄바꿈 | O |
| 가로 · 세로 정렬 | O |
| 열너비 · 행높이 | O |
| 취소선 **색** | X — 엑셀은 취소선 색을 글자색과 따로 지정할 수 없음 |
| 표 바깥의 글, 그림, 글상자 | X — 표만 변환함 |

### 알아둘 점

- 문서에 표가 여러 개면 **시트를 나눠서** 저장하고 알려줍니다.
- 표가 글상자·그리기 개체 안에 있으면 누락될 수 있고, 그런 경우 경고를 띄웁니다.
- 암호가 걸린 문서와 배포용(복사방지) 문서는 변환할 수 없습니다.
- 여러 파일을 처리할 때 **하나가 실패해도 멈추지 않고** 끝까지 진행한 뒤 실패 목록을 보여줍니다.
- 한/글 전용 글꼴(함초롬돋움 등)이 PC에 없으면 엑셀이 다른 글꼴로 대체합니다.
  `hwp2xlsx.py` 상단의 `FONT_MAP` 에 `{"함초롬돋움": "맑은 고딕"}` 처럼 적으면 바꿔 넣습니다.
- 지원 형식은 **HWP 5.0** 입니다 (2002년 이후 한/글). 그 이전 `.hwp 3.0` 은 안 됩니다.

## 개발자용

### 직접 실행

```bash
pip install -r requirements.txt
python hwp2xlsx.py                      # 스크립트가 있는 폴더의 *.hwp
python hwp2xlsx.py 입력폴더 출력폴더        # 폴더 지정
python hwp2xlsx.py a.hwp b.hwp          # 파일 지정
```

`hwp2xlsx.py` 상단의 `IN_DIR` / `OUT_DIR` 로 기본 경로를 고정할 수도 있습니다.
비워두면 실행 파일이 있는 폴더를 씁니다.

### exe 빌드

`v` 로 시작하는 태그를 올리면 GitHub Actions 가 자동으로 빌드해서 Release 에 첨부합니다.

```bash
git tag v1.0
git push origin v1.0
```

태그 없이 빌드만 하려면 Actions 탭에서 `build-exe` 워크플로를 수동 실행하면 됩니다.
결과물은 Artifacts 에 올라옵니다.

로컬 빌드:

```bash
pip install pyinstaller
pyinstaller --onefile --console --name hwp2xlsx --exclude-module numpy hwp2xlsx.py
```

### 동작 방식

.hwp 5.0 은 OLE 복합문서이고 내부 스트림이 zlib(raw deflate)로 압축되어 있습니다.

1. `DocInfo` — 글꼴 이름, 테두리/채우기, 글자모양, 문단모양 목록을 읽음
2. `BodyText/SectionN` — 레코드 트리에서 표(`HWPTAG_TABLE`)와 셀(`HWPTAG_LIST_HEADER`)을 찾음
3. 셀마다 위치 · 병합 범위 · 크기 · 테두리ID · 세로정렬을 뽑고, 문단과 글자모양 런을 복원
4. xlsxwriter 로 기록

### 왜 openpyxl 이 아니라 xlsxwriter 인가

openpyxl 은 문자열을 **항상** `t="inlineStr"` 로만 저장합니다 (`openpyxl/cell/_writer.py`).
그런데 엑셀은 리치텍스트 런(`<r>`)을 **sharedStrings 에 있을 때만** 인정합니다.
인라인 문자열 안의 런은 무시하고 마지막 것만 남깁니다.

그 결과 한 칸에 색이 섞인 셀에서 앞부분이 통째로 사라지고 색도 잃습니다.
XML 자체는 정상이라 파일만 봐서는 발견되지 않고, 엑셀에서 열어야 드러납니다.

xlsxwriter 는 `sharedStrings.xml` 에 제대로 기록합니다. 이건 엑셀이 직접 저장할 때
쓰는 형식이라 안전합니다.

### 단위 환산

- HWPUNIT = 1/7200 인치
- 행높이(pt) = HWPUNIT / 100
- 열너비: 픽셀 = HWPUNIT / 7200 × 96, 저장값 = (픽셀 − 5) / 7
  - xlsxwriter 는 넘긴 값에 5/7 을 더해서 저장하므로 미리 빼줘야 함
